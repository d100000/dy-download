常见问题

抖音无水印下载与分享：在抖音 App 复制作品分享链接，粘贴到本站点击解析，即可在线预览、下载无水印原片，或一键生成分享页发给微信好友——对方点开即可观看，无需安装抖音 App。无需登录抖音账号；基础解析不要求注册本站账号，也无需安装应用。

这个抖音下载器会处理和保留哪些数据？

前端代码开源可审查。本站不保存视频或图片文件，兼容线路只做流式转发。浏览器会生成一个30 天有效的随机第一方匿名 ID；为提供免费额度、防滥用和播放诊断，服务端会把 IP 和该 ID 转为用途化摘要。这些摘要、粗粒度浏览器信息、访问/解析/播放事件及 API 任务结果的保留期最多设为 30 天，到期后由每 5 分钟运行的任务删除。站内账号可选；注册时保存邮箱与加盐密码哈希。每次解析都会把规范化后的作品链接提交给第三方服务 AnyToCopy，以获取作品信息和媒体地址；普通解析默认不获取语音文案，只有你主动打开「获取文案」时才请求语音转文字。浏览器直连媒体时，媒体源会收到你的网络与浏览器信息；视频下载则由本站代理流式转发。

怎么把抖音视频分享到微信？发出去是卡片还是链接？

解析后点生成分享页，得到一条链接。想让好友收到带封面和标题的卡片，要在微信里打开这个页面，再点右上角 ··· →「发送给朋友」——这样转发出去才是卡片。如果只是复制链接、粘贴到聊天窗口，微信不会把网址展开成卡片，会显示成一条普通网址（这是微信的机制，任何网站都一样）。两种方式好友点开都能直接观看无水印原片，无需安装抖音 App、不用复制口令跳转。

分享给朋友后，对方需要装抖音 App 吗？链接会过期吗？

不需要装任何 App，用微信内置浏览器点开就能看。分享页匿名有效期 7 天、登录后 30 天；页面只保存作品的标题封面等信息，不存储任何视频文件，版权仍归原作者。你也可以生成分享海报（带二维码），长按保存后发朋友圈。

需要登录或安装软件吗？

无需登录抖音账号，也无需安装任何 App 或浏览器插件。本站账号为可选；基础解析可直接使用，API 控制台等账号功能需要登录。

下载的抖音视频有水印吗？

没有水印。下载的是无水印原片，也不会加入本站自己的二次水印。

支持图集（图片作品）下载吗？

支持。图集作品会自动识别，可逐张下载原图，也可批量解析下载。

有没有 API 可以批量调用？

有。登录后可在 API 控制台生成密钥，通过异步接口批量提交链接并查询结果，按次计费。

怎么提取抖音视频的文案（语音转文字）？

解析后打开结果卡上的「获取文案（语音转文字）」开关即可自动提取，通常 1–3 分钟完成，可复制全文或试听音频。该功能需要登录，注册用户每天有免费提取次数；同一视频全站只提取一次，命中缓存不重复扣次。详见文案提取。
