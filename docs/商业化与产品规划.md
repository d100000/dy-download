> 版本：v0.1 ｜ 日期：2026-07-25 ｜ 基于[分享页功能规划](分享页功能规划.md)
> 视角：AI 产品经理 / 营销产品经理 / 网创（个人与小团队变现）

## 0. 战略定位：从工具到入口

现在的产品是一个**功能完备但天花板明确**的工具站：解析 → 下载，用完即走，用户不留存、不传播、不付费。它的三个真实资产是：

1. **稳定的免签解析链路 + 代理池**——同类工具最容易挂的地方，这里做得比大多数同行扎实
2. **已建成的商业化基建**——用户体系、按次计费 API、异步任务、数据后台、防薅羊毛，这些通常是工具站最缺的
3. **“开源可审查 · 数据最小化 · 永不接广告”的信任心智**——在这个到处是弹窗和二次水印的品类里，是稀缺的差异化

分享页是把这三个资产接上**传播**与**留存**的那根线：

```
下载器（拿走就走）  →  分享页（内容有了落地页）  →  内容中转站（AI 增强 + 多平台）
   工具价值              传播价值 + 数据资产          生产力价值 + 订阅
```

**一句话战略：不要做"更好用的下载器"，做"抖音内容的中转与再创作入口"。** 下载只是入口动作，分享页是留存载体，AI 是溢价来源。

## 一、AI 产品经理视角

### 1.1 核心判断

下载和分享本身**没有 AI 含量，也不该硬塞 AI**。AI 的价值在于回答用户拿到这条视频之后的下一个问题：*"这条视频讲了什么 / 它为什么火 / 我怎么做一条类似的"*。

分享页是 AI 能力最好的**分发面**——因为它是唯一一个"用户会反复打开、且会给别人看"的页面。AI 摘要出现在分享页上，是**给传播链路上每一个人做的产品演示**。

### 1.2 能力分层

| 层 | 能力 | 用户价值 | 技术路径 | 优先级 |
|---|---|---|---|---|
| L1 理解 | ASR 转文字稿 | 视频→可搜索、可复制的文本 | 只拉音频轨转录，转完即删，不存视频 | ⭐⭐⭐ |
| L1 | 智能摘要 / 要点 | "30 秒它说了什么" | 小模型批量处理，成本极低 | ⭐⭐⭐ |
| L2 分享页增强 | **字幕**（含双语） | **微信里默认静音浏览，字幕直接决定完播率** | 基于 ASR 时间戳渲染 | ⭐⭐⭐ |
| L2 | AI 摘要卡 | 分享页首屏就有信息量，转发意愿↑ | 复用 L1 | ⭐⭐⭐ |
| L3 再创作 | 转小红书/公众号/口播稿 | 直接产出可发布内容 | 文本改写 | ⭐⭐ |
| L3 | 封面/标题重生成 | 二创提效 | 文生图 + 文案 | ⭐ |
| L4 数据 | 爆款拆解（钩子/结构/BGM/时段） | 选题决策 | 需积累样本 | ⭐⭐ |
| L4 | 账号监控 / 选题推荐 | B 端刚需，可高价 | 定时任务 + 沉淀库 | ⭐ |

**最值得先做的是 L2 字幕**：它同时解决了"微信静音看不懂"（体验）、"分享页有独特价值"（差异化）、"AI 能力可被看见"（转化）三件事，而且是唯一一个**接收方也能感知到 AI 价值**的功能。

### 1.3 成本与定价倒推

| 项 | 量级估算（需实测校正） | 说明 |
|---|---|---|
| 解析 | ≈ 0 | 自有链路，只耗代理流量 |
| ASR（自托管 Whisper） | 1 分钟视频约 ¥0.00X | 需 GPU 或较慢的 CPU 推理；起量后自托管明显划算 |
| ASR（云服务） | 1 分钟约 ¥0.0X | 零运维，适合冷启动 |
| 摘要/改写（小模型） | 单条 ¥0.00X 级 | 千字级输入，成本可忽略 |
| 深度爆款分析（大模型） | 单条 ¥0.0X–0.X 级 | 只对付费用户开放 |

**定价原则：AI 功能一律走“整批预授权—持久化执行—逐项结算—失败退款”**，直接复用现有 `job_items`、数据库租约与 `api_ledger` 账本模型。创建任务必须在一个事务里冻结全额，成功才从 `reserved_cents` 转入 `spent_cents`，失败则原子退回 `balance_cents`；`Idempotency-Key`、CAS 结算与启动对账缺一不可。这套逻辑已经写好且并发、重启安全，是本项目做 AI 商业化最大的现成优势——同行做到这一步通常要额外两周。

**成本护栏（必须有，否则一次滥用就亏穿）**：单视频时长上限（如 10 分钟）、每日每用户次数上限、同一 `item_id` 结果缓存复用（热门视频只转录一次，收 N 次钱）。最后这条是**毛利结构的关键**：ASR 成本是一次性的，收入是按次的。

### 1.4 数据飞轮

```
解析记录（已有 request_logs / api_logs）
   → 作品元数据沉淀（标题/标签/BGM/互动数/发布时间）
   → 内容特征库
   → 爆款要素模型
   → 选题推荐 / 赛道报告（B 端可高价售卖）
```

结构化元数据可以支持后续的内容理解与推荐，但不能因为数据公开就默认把每次解析沉淀成商业资产。**只为已经明确告知的产品功能留存最少字段，并设置清晰期限**；默认不把用户解析内容用于训练、画像或商业分析。若未来需要建立内容特征库，应单独说明用途、取得适用的授权或同意、做去标识化并提供退出机制，不能用“不保存媒体文件”替代完整的数据披露。

### 1.5 AI 侧的红线

- AI 生成内容需标注"AI 生成"，不为准确性做承诺
- 不做"AI 洗稿/去重过审"类卖点——这是明确的灰产定位，会毁掉现有的信任心智，且平台打击优先级最高
- 转录音频属于临时处理，**必须转完即删**，并在隐私说明里写清楚，否则与"服务器不存内容"的核心承诺自相矛盾

## 二、营销产品经理视角

### 2.1 增长模型

现在的获客是**纯搜索驱动的线性增长**：SEO 投入多少，流量来多少，用户用完就走。分享页第一次引入了**非线性项**：

```
新增用户 = SEO 自然量 + 分享页带来的新访客
分享页新访客 = 创建数 × VPS × CTA点击率 × 落地转化率
```

三个流量池及其角色：

| 流量池 | 现状 | 角色 |
|---|---|---|
| SEO（工具词） | 已有 hreflang / JSON-LD / FAQ / HowTo 结构化数据，基建扎实 | **基本盘**，稳定但增长慢，天花板 = 搜索量 |
| 微信社交（新） | 0 | **爆发项**，也是风险项（域名封禁） |
| 开发者 API | 已有文档站 + 控制台 | **利润项**，客单价最高，最稳定 |

### 2.2 转化漏斗与付费墙位置

```
访问首页 → 解析成功 → 生成分享页 → 注册 → 感知额度限制 → 付费
  100        ~40         ~8          ~3        ~1.5        ~0.05-0.15
```

（转化数字为行业量级假设，需按真实数据校正）

**付费墙该放在哪里，是本方案最重要的一个判断。**

现有付费墙是"每天 3 次 / 登录 10 次"的**次数墙**。次数墙的问题是：它惩罚的是轻度用户（偶尔用一次的人被卡住直接流失），而重度用户里真正愿意付钱的那批人，其实不在乎次数——他们在乎**能力**。

**建议把付费墙从"次数"迁移到"能力"**：

| 免费 | 付费 |
|---|---|
| 解析、下载、生成分享页（放宽次数） | 分享页长期有效 / 永久 |
| 分享页 7 天有效、带站点页脚 | **去水印白标**（去页脚品牌） |
| 基础元数据 | AI 字幕 / 摘要 / 文案改写 |
| 单条解析 | 批量、合集页、Excel 导出 |
| 无数据 | 分享页访问数据看板 |
| — | 自定义域名（B 端） |

理由：次数放宽能显著提升分享页创建量，而分享页创建量直接决定获客量；被放弃的那点次数限制收入，远小于传播带来的增量。**用免费额度换传播，用能力差异换付费。**

### 2.3 品牌与信任资产

“开源可审查 · 数据最小化 · 永不接广告”是本产品最难被抄的信任资产——同行抄得走代码，抄不走“不接广告”的承诺（因为广告是他们唯一的收入）。其中“数据最小化”必须落到具体事实：不保存媒体文件、站内账号可选、用途化摘要/粗粒度事件/API 任务的保留期最多设为 30 天且到期后由每 5 分钟运行的任务删除，并明确浏览器直连抖音会向抖音披露请求方网络与浏览器信息。

**运营上要把它坚持到底**：分享页上不出现任何第三方广告位，哪怕流量很大。广告收入 = 一次性变现流量；不接广告 = 长期建立"这个站可以放心发给别人"的心智——而**分享页产品成立的前提恰恰是"敢不敢把这个链接发到工作群"**。这两件事是同一件事。

### 2.4 渠道打法

| 渠道 | 动作 | 优先级 |
|---|---|---|
| SEO | 继续做长尾工具词；新增"抖音链接怎么发微信""抖音链接微信打不开"等**问题词**——这批词精准命中分享页功能 | ⭐⭐⭐ |
| 微信自传播 | 分享页 CTA + 海报图（图片抗封） | ⭐⭐⭐ |
| 内容平台 | 小红书/知乎/B站做"素材整理工作流"教程，工具作为解决方案自然植入 | ⭐⭐ |
| 开源引流 | `oss/` 精简版已在 GitHub → README 引导到完整版/在线版，**这是现成的开源引流漏斗，目前没被充分利用** | ⭐⭐ |
| 开发者社区 | API 文档站已有，去工具站/爬虫/自动化社区做分发 | ⭐⭐ |
| 分销 | 老用户推广得额度/分成 | ⭐ |

### 2.5 定价方案

| 档位 | 价格（假设） | 权益 |
|---|---|---|
| 免费 | ¥0 | 解析下载、分享页 7 天、带品牌页脚 |
| 个人会员 | ¥9.9/月 · ¥69/年 | 分享页 365 天、去页脚、访问数据、批量、Excel |
| 创作者 | ¥29/月 · ¥199/年 | + AI 字幕/摘要/改写额度、合集页、优先解析 |
| 团队/企业 | ¥99+/月 | + 自定义域名、白标、多席位、更高 API 额度 |
| 开放 API | 按次（后台 `api_price_cents` 可调） | 解析 < 分享页生成 < AI 处理，三档定价 |

年付要给足折扣——工具类产品的月付续费率通常很差，年付是把 LTV 一次性锁定的主要手段。

## 三、网创视角（个人 / 小团队怎么把它变成钱）

### 3.1 这个项目的真实底牌

坦白讲，工具站本身很难做成大生意；但这个项目有三个**别人没有**的东西，决定了它的变现路径和普通工具站不一样：

1. **计费基建已建成**：用户、API Key、余额、原子扣费、异步任务、数据后台全都有。绝大多数同行卡在"想收钱但没系统"。
2. **代理池 + 反封基建已建成**：解析类工具的真实门槛不在解析代码（网上都有），而在"能长期稳定不挂"。这是可以直接卖给同行的能力。
3. **开源精简版 + 完整版的双轨已成型**（`oss/`）：这是经典的 open-core 引流结构，**已经搭好但还没启动**。

### 3.2 变现路径排序（按"启动难度 ÷ 回报"）

| # | 路径 | 启动难度 | 回报 | 说明 |
|---|---|---|---|---|
| 1 | **API 卖给同行** | 低（已有） | 中高 | 网创圈大量人做工具站/小程序但搞不定稳定解析。你卖的是"稳定"，边际成本近零，**这是最被低估的一条** |
| 2 | 会员订阅 | 低 | 中 | 需要先有分享页带来的用户量 |
| 3 | **卖部署/源码/白标站** | 低（已有 oss 引流） | 中高 | GitHub 精简版引流 → 完整版商业授权 + 代部署。单笔客单价高，交付一次性 |
| 4 | 私域 + 高客单服务 | 中 | 中高 | 分享页 → 公众号 → 素材整理/剪辑/代运营接单 |
| 5 | AI 增值服务 | 中 | 中 | 字幕/文案，有真实付费意愿 |
| 6 | 分销返佣 | 低 | 低中 | 放大已有转化 |
| 7 | ~~广告~~ | — | — | **不做**，与品牌承诺冲突（见 §2.3） |

**给个人开发者的建议顺序：先 1 和 3（有现成基建、来钱快、不依赖流量规模），用它们养住服务器和代理成本；同时用分享页做用户量，量起来后再上 2 和 5。**

### 3.3 单位经济模型

**成本结构（月，假设中等规模）**

| 项 | 估算 | 说明 |
|---|---|---|
| 服务器 | ¥50–200 | 单体 FastAPI + SQLite，1–2 核够用 |
| 代理池 | ¥100–500 | 住宅代理按量/按月，**解析量的主要变动成本** |
| 域名池（3–5 个） | ¥20–50 | 分享域名必然要备用 |
| 分享页兜底带宽 | **¥0–数百，波动最大** | 见下 |
| AI（若开） | 按量 | 有次数护栏则可控 |

**兜底带宽是唯一可能失控的成本**，必须算清楚：

- 一条视频约 5–15 MB
- 若微信内直连成功率高（乐观）→ 兜底占比 5–10% → 10 万次播放约 50–150 GB → 成本可控
- 若微信内**必须**走兜底（悲观，取决于[实测清单](分享页功能规划.md#10-p0-实测验证清单开工第一天做全部通过才继续)第 1 项）→ 10 万次播放 = 0.5–1.5 TB → 成本量级完全不同，产品形态需要重设计（如：微信内只给封面+摘要，播放引导到浏览器）

👉 **所以那条实测必须在写第一行业务代码之前完成。** 这不是技术细节，这是商业模型的分叉点。

**收入侧盈亏平衡（粗算）**：按上表中位成本 ~¥500/月，只需 ~50 个个人会员（¥9.9）或 ~5 个企业客户或少量 API 客户即可打平。**这是一个门槛很低的盈亏平衡点**，意味着这件事值得做——难的不是回本，是增长。

### 3.4 冷启动节奏

| 阶段 | 重点 | 成功标准 |
|---|---|---|
| 0–2 周 | 微信实测 + 分享页 MVP + 灰度域名 | 微信里能打开能播 |
| 3–6 周 | 埋点跑通、VPS 测出真值、开源版发布引流 | VPS > 1（每个分享页至少带来 1 个访客） |
| 2–3 月 | 会员上线、API 对外推、私域承接 | 首批付费用户，验证付费意愿 |
| 4–6 月 | AI 字幕、合集页、白标 | 月流水覆盖成本 3 倍以上 |

**每个阶段都设一个"不达标就砍"的止损线**——工具类项目最大的浪费不是做错方向，是在没验证的方向上持续投入。

### 3.5 风险登记册

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| **微信封分享域名** | **高（近乎必然）** | 高 | 域名池 + 短码解耦 + 文案自律 + 流量沉淀到公众号 |
| 抖音改分享页结构 | 中 | 高 | 解析层已隔离在 `_parse_share()`；加监控告警 + 快速修复预案 |
| 代理池整体被封 | 中 | 高 | 已有 `force_proxy` 保护与自动封禁自愈；多供应商分散 |
| 版权投诉 / 律师函 | 中 | 中高 | noindex + 有效期 + 强制署名回链 + 投诉即下架 + 不落地存储 + 创建者可追溯 |
| 主体与支付合规 | 中 | 中 | 虚拟商品退款政策要写清楚；规模化后需企业主体与发票能力 |
| ICP 备案卡住 | 中 | 中 | 提前 20–30 天启动，别等功能做完 |
| 同质化竞争 | 高 | 中 | 护城河是"稳定 + 不接广告 + 分享页"，不是解析本身 |
| 单点维护（一个人） | 高 | 中 | 单体架构反而是优势；写好运行手册，别把知识只放脑子里 |

### 3.6 关于合规的直话

分享页把产品从"个人工具"推到了"内容再分发"，这是**性质的改变**，不是程度的改变。前面方案里的 noindex、有效期、强制署名、投诉下架、不落地存储，不是为了合规好看，是为了在收到第一封投诉时，你有一套能证明"我们是链接工具而非盗版站"的完整证据链。

同时也要现实：**这类产品长期看是在平台规则的灰度地带运营的**。合理的做法是把它当作一个**中期现金流项目**来经营——尽早把收入结构往"卖能力"（API、部署、白标、AI 服务）倾斜，而不是全押在"面向 C 端的免费流量"上。前者不依赖微信和抖音的脸色，后者随时可能一夜归零。

## 四、三视角的交汇：如果只能做三件事

1. **先做那条微信播放实测**（3 天）——它决定成本模型和产品形态，不做就是在赌博
2. **分享页 MVP + AI 字幕**（1 个月）——字幕是唯一一个让接收方也感知到价值的功能，同时撑起传播和付费两条线
3. **启动开源引流 + API 外销**（并行，2 周）——用已经建好但闲置的基建，先把成本养活，给 C 端增长争取时间

其余的都可以等数据说话。
