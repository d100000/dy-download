# 抖音无水印下载器 · 软件介绍

> 一句话：**粘贴分享链接，即可在线预览并下载抖音视频与图集的无水印原片**——视频播放与图片优先直连抖音 CDN，视频下载由服务器代理流式转发，所有媒体均不落地、不存储。在此之上，配套了完整的用户体系、开放计费 API、运营数据后台与代理稳定性方案，是一套可自建、可商业化的短视频解析平台。

---

## 一、它能做什么（核心能力）

### 1. 解析与下载
- **无水印解析**：自动识别视频作品与图集（多图）作品，提取无水印原片地址。
- **可靠流式下载**：视频先做 1 字节 Range 预检，再从同源签名地址由浏览器原生流式保存；图片仍由浏览器直连。服务器只转发视频字节、不落地媒体，部署时需按下载量规划带宽。
- **在线预览**：解析后可直接在线播放视频、浏览图集，再决定是否下载。
- **批量解析**：一次粘贴多条文案/链接（或上传链接文件），自动拆分、去重、逐条解析。
- **表格视图 + 导出 Excel**：批量结果以表格展示（封面/标题/作者/类型/时长/互动数据/操作），一键导出为真正的 `.xlsx`。
- **结构化元数据**：标题文案、作者与主页、话题标签、背景音乐、拍摄位置、点赞/评论/收藏/分享、封面、时长、分辨率等一并返回。

### 2. 账户与风控
- **注册 / 登录**：邮箱注册，密码 PBKDF2 加盐哈希存储。
- **滑块验证码**：服务端渲染 PNG 缺口拼图（答案不在返回体里）+ 行为轨迹检测 + 工作量证明（PoW）+ 蜜罐字段 + **一次性、限时、绑定 IP 的 HMAC 通行令牌**，有效防脚本/防抓包重放/防跳过。
- **防薅羊毛限频**：按**浏览器指纹 + IP 双维度**计数，匿名每天 3 次、登录用户每天 10 次；换指纹绕不过 IP，换 IP 绕不过指纹。
- **防爆破**：注册/登录按 IP 限频，验证码签发限频防 CPU-DoS。

### 3. 开放 API（可商业化）
- **异步任务模型**：`POST /api/v1/jobs` 提交批量链接→返回 `job_id`→`GET /api/v1/jobs/{id}` 轮询结果，规范化 `{code, message, data}`。
- **按次计费**：每成功解析一条链接计费一次（默认 ¥0.01/条，后台可配单价），失败不计费，余额不足拒绝提交；扣费采用原子「预扣—结算—失败退款」，并发安全。
- **开发者控制台**：登录后自助生成/删除 API Key、查看余额与用量、在线测试任务。
- **公开接口文档页**：`/api-docs`，含鉴权、接口、计费、错误码说明。

### 4. 运营数据后台
- **数据概览**：总用户、今日新增、PV/UV、使用次数、API 调用、营收、回访率。
- **趋势分析**：近 14 天新增用户 / 浏览 / 独立访客 / 解析使用 / API 调用 / 营收折线。
- **用户与日志**：用户列表（可停用/调额度）、网页请求记录、API 请求与计费记录。
- **API 定价与充值**：后台配置单价、给密钥充值。

### 5. 代理与稳定性
- **代理 IP 池**：支持 http/https/socks5，多代理轮换、失败自动转移、健康检测、被封自动禁用；后台可视化管理。
- **抗封设计**：解析走代理不暴露服务器真实 IP；媒体走浏览器直连进一步降低服务器暴露面。

### 6. 流量与国际化
- **中英双语**：`?lang=` 服务端切换，右上角一键切换，cookie 记忆。
- **SEO**：分语言的 title/description、canonical、hreflang 交替链接、sitemap、robots、Open Graph / Twitter Card。
- **GEO（面向 AI 搜索）**：分语言的结构化数据 JSON-LD（WebApplication / FAQPage / HowTo），利于被搜索引擎富结果与 AI 引用。
- **性能**：整页内联、零外部请求；动效仅用 transform/opacity（GPU 合成），利于 Core Web Vitals。

## 二、实现方案（架构与原理）

### 解析与下载链路

```
用户粘贴分享链接
      │
      ▼
[1] 短链跳转解析 ──► 从 v.douyin.com 短链的 302 Location 取出作品类型与 item_id
      │
      ▼
[2] 拉取分享页(reflow) ──► www.iesdouyin.com/share/... （可走代理，防封 IP）
      │
      ▼
[3] 解析 _ROUTER_DATA ──► 从页面内嵌 JSON 提取标题/作者/统计/无水印地址/图集图片
      │
      ▼
[4] 返回结构化 JSON（元数据 + 播放直链 + 视频签名下载地址）
      │
      ▼
[5] 播放/图片直连 CDN；视频下载 1 字节预检后经服务器代理原生流式保存
```

**关键点**：服务器处理分享页 HTML、元数据 JSON，并流式转发视频下载字节；普通浏览器播放与图片仍是 **浏览器 ↔ 抖音 CDN** 直连。视频不落地保存，但下载会消耗服务器代理出口和带宽。

### 技术栈
- **后端**：Python 3 + FastAPI + uvicorn（异步任务用后台线程）。
- **存储**：SQLite（用户、会话、API Key、任务、请求日志、每日用量、设置——启用 WAL 并发读）+ JSON 文件（代理池配置）。
- **前端**：纯原生 HTML/CSS/JS，**无框架、无构建步骤、零外部依赖**，单文件页面，内联样式与脚本。
- **依赖**：仅 `fastapi` / `uvicorn` / `openpyxl`（Excel 导出）/ `PySocks`（socks5 代理，可选）。极轻、易自建。

### 安全设计
- 密码 PBKDF2-HMAC-SHA256 加盐（12 万次迭代）。
- 会话 Cookie：HttpOnly + SameSite，生产可开启 Secure。
- 滑块验证：答案仅存服务端与像素中；一次性 HMAC 令牌防重放/防跳过。
- 反 SSRF：媒体代理域名白名单 + 跟随重定向后复核最终域名。
- 反爬保护：仅可信反代才采信 `X-Forwarded-For`，避免伪造头绕过 IP 风控。
- 敏感数据（真实代理账密、用户库）全部落在 `data/` 且被 gitignore，不入代码库。

### 部署形态
- **单机**：安装依赖后以 `uvicorn server:app --no-access-log` 启动；仓库脚本也默认关闭访问日志。
- **Docker**：一键构建运行，环境变量注入密钥与配置。
- **私有部署**：可完全离线自建，数据自持。
- 关键环境变量：`ADMIN_PASSWORD`、`CAPTCHA_SECRET`、`TRUST_PROXY`、`COOKIE_SECURE`、`API 单价` 等。

## 四、能力泛化（可延展的方向）

当前实现聚焦抖音，但**架构是通用的"短视频解析 + 签名流式下载 + 计费 + 后台"底座**，可向以下方向泛化：

### 1. 多平台泛化
同构的"分享页解析"思路可复制到 **快手、小红书（图文）、微博、B 站、TikTok、YouTube Shorts** 等——把"解析器"做成可插拔的平台适配层，一套下载/计费/后台复用到多平台。

### 2. 内容工作流泛化（价值最高）
把"下载"从终点变成**流水线第一步**：
`下载 → 去重/伪原创改写（改分辨率/首尾帧/背景音，或接 AI 改写）→ 多账号管理 → 定时发布 → 数据回收`。这才是矩阵运营、跨境搬运真正付费的完整工作流。

### 3. 数据 / 素材监控泛化
把解析能力包装成**结果型服务**：竞品爆款素材监控、电商选品、品牌 UGC 归档、话题/BGM 趋势追踪——卖"帮你盯素材"，而非卖一个下载接口。

### 4. AI 能力泛化
在结构化数据之上叠加 AI：**文案/字幕提取、语音转写、内容改写/伪原创、自动打标签、选题建议、数据看板**。

### 5. 能力输出泛化
以**开放 API / 白标 / 私有化**形式对外输出解析与工作流能力，服务开发者与企业客户。
