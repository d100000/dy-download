**元数据旁路实施与验证 · v1.34.3 · 2026-09-28**

已完成代码接入、离线回归、真实 Linux worker 请求与浏览器界面验证。实际云服务器尚未部署；本轮没有修改生产数据或重启现有应用服务。

最终 Linux 验收中，HTTP 优先模式 **11/11**、关闭 HTTP 的纯浏览器模式 **11/11** 均取得同作品完整文案。原短链在游客会话就绪后的 5 次请求中，HTTP 优先模式中位 **0.426 秒**，纯浏览器模式中位 **2.332 秒**。这些是当前生产 worker 代码的真实请求结果，不是之前独立 SDK 基准的数字。

**实施内容**

- 保留主媒体解析与元数据旁路并行；HTTP 核心复用连接和专用匿名游客会话，失败后在同一总时限内转到网页。
- 首次请求由独立 Chromium 获取标题和游客会话。HTTP 最长复用游客身份 5 分钟或 64 次尝试；浏览器 context 限制 5 分钟或 32 次页面任务，每条任务单独页面与捕获列表。
- 取消固定 2 秒无标题就刷新。仅明确的 408/5xx 可有界恢复一次，429 不自动刷新；有效同作品结构化标题不再强制等待 0.5 秒。
- 统一识别省略号、显式截断标记及“版本过低，升级后可展示全部信息”。显示标题发生本地长度裁剪时保留 partial 状态，正文独立保存并标记完整度。
- 回填标题、正文、作者、发布时间、四项互动、时长、尺寸、封面和话题；父进程再次执行白名单过滤，不能传递 SDK 原始响应、Cookie 或媒体线路。
- 首页单条、批量行、已打开弹窗和分享页可更新已有信息区域，保留播放器节点、播放进度与图集状态。
- 继续保护人工标题、有效 0 计数、同作品 ID/类型、媒体地址、计费与分享有效期。签名轮询只读本地快照，不启动网络或扣费。
- 支持独立 Python 3.12、显式代理、安全子进程环境、有界队列、单个 worker 故障恢复，以及最近 32 次任务的脱敏阶段记录。

HTTP 核心固定 Evil0ctal 的提交 `737bf3dfe9de1dbff57990c0ec4c9e02c75c3d0f`；归档 SHA256 为 `8da662c5656ae039678b82cbc0688253537760b1f6fccbf037858c2c23f3e18e`。保留包内 Apache-2.0 许可，不复制或重写签名算法，不运行其全栈 API、数据库和调度服务。安装与运行均校验来源摘要。

环境：Lima Ubuntu 24.04.4 ARM64、Python 3.12.3、Playwright 1.63.0、Chromium 153.0.8010.12。单 worker、任务间隔 1 秒、每任务 **6 秒**总预算，包含排队和 IPC；没有作品结果缓存。浏览器启动与 ready 等待单列约 **0.353 秒**。网络仍是本机代理出口，不是云服务器机房 IP。

**环境问题和中间失败保留记录**

本机网络将域名解析为 `198.18.*` fake-IP，生产公网 DNS 策略会拒绝。未放开私网地址检查，也没有把假 IP 加入白名单。

为模拟可正常解析公网地址的 Linux 环境，仅在测试 VM 临时配置 DNS-over-HTTPS。初版 Google DoH 转发器每次查询成本高，早期浏览器 **0/11** 在 6 秒内取得有效文案，失败记录保存在 `browser-current.jsonl`；一次独立诊断进一步发现单个不相关直播域 DNS 查询可达约 16 秒。这些不能算入最终修复版本的验收成功率，也没有从诊断目录删除。

改进测试 DNS 的连接复用与按实际 TTL（最多 60 秒）缓存后，Google 条件下 HTTP 优先原短链后续 **5/5**，中位 **0.494 秒**；首次会话 **3.634 秒**。该批次的一个已知 ID 被较严格的空白比较判为不一致，原因是 DOM 去掉的换行在 HTTP 标题中变成空格；最终批次恢复前次审查的统一归一规则，并保存正文供复核。没有修改平台返回文案来通过比较。

公共 DoH 对照中，AliDNS 首次连接约 52 ms、同连接后续约 11–13 ms，系统 A+AAAA 解析约 43 ms，地址均为公网。最终两组在这一配置下测试；切换后仅预先验证了一次 www 域名，没有为最终批次预热全部资源域名。详见 `data/diagnostics/metadata-dns-probe-20260927/`。这项 DNS 设置只用于测试 VM，不作为应用依赖或新增代理绕过能力。

真实网页还暴露出两个缺失的安全 SDK 资源主机；代码仅加入其精确主机 `lf-security.bytegoofy.com` 和 `lf-security-backup.bytegoofy.com`，继续执行公网 DNS、HTTPS、导航与资源类型限制，并阻止无关的 `live.douyin.com` 请求。全量安全 route 仍保留，因此没有声称浏览器 HTTP 缓存已经恢复。

另发现同步 Playwright 占用事件循环，导致同线程运行 HTTP asyncio loop 失败；已将 HTTP 连接池放入专用线程，并通过 Linux 真实 Playwright 上下文、离线运行中事件循环回归及最终平台请求验证。

**部署方式**

```bash
PYTHON=python3.12 bash tools/install_metadata_runtime.sh
.venv-metadata/bin/python -m playwright install --with-deps --only-shell chromium
```

安装到仓库 `.venv-metadata` 后自动发现；安装到其他目录时配置 `BROWSER_TITLE_PYTHON`。浏览器安装与服务运行的 `PLAYWRIGHT_BROWSERS_PATH` 必须一致。`METADATA_HTTP_ENABLED=1` 为默认值；需要代理时显式设置 `BROWSER_TITLE_PROXY_URL`，并确认系统 DNS 返回真实公网地址。主应用仍使用原 `.venv`。

Docker 可选构建：

```bash
docker build --build-arg WITH_METADATA_HTTP=1 -t douyin-dl:1.34.3 .
```
